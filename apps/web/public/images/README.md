# Ilustración del perfil

`profile-reading-nook.png` es una ilustración independiente creada con la habilidad
imagegen y la herramienta integrada, usando el mockup adjunto como referencia de
estilo. No contiene la interfaz, nombres, estadísticas ni texto superpuesto. La
interfaz real se construye con React y CSS. La portada todavía no es editable.
