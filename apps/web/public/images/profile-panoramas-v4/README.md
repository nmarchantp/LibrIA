# Profile panoramas v4

23 WebP scene extensions generated with the built-in imagegen tool from each theme's original banner. These are used by the panoramic personal profile header. Pacto de Sangre keeps its previously approved extended asset.

The exact prompts, source/output paths, encoding script, dimensions and visual contact sheet are in `artifacts/profile-panorama-v4/` at the repository root. No generation CLI was used.
